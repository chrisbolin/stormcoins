# STORMCOINS

Get coin, land, repeat. Play at https://chrisbolin.co/stormcoins/

## Development

Requires Node 22.12+.

```sh
npm install
npm start          # http://localhost:3000/stormcoins/
npm test
npm run typecheck
npm run lint
```

Press `d` in the game to show or hide the debug panel.

Pushing to `master` builds and deploys to GitHub Pages.
